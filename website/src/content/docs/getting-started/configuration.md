# 配置手册

limedl 提供了细致而强大的配置体系。所有配置项均统一维护于应用数据目录中的 `settings.json` 文件中，并通过 Rust 内存事务与磁盘原子重命名（`.json.tmp` → `.json`）确保高并发读写安全与防损坏。

在客户端主界面中，点击左侧工具栏的 **设置** 图标（或使用快捷键）即可打开图形化设置面板。

---

## 1. 常规与外观 (General & Appearance)

| 配置项 | 可选值 / 类型 | 默认值 | 详细说明 |
| :--- | :--- | :--- | :--- |
| **界面语言** | 简体中文 / 繁體中文 / English | 跟随系统语言 | 切换界面的显示语言，即时生效。 |
| **主题色彩** | 深色 / 浅色 / 跟随系统 | 跟随系统 | 支持现代深色与浅色外观，支持跟随操作系统明暗模式自动无感切换。 |
| **关闭主窗口行为** | 最小化到托盘 / 退出应用 | 最小化到托盘 | 选择点击主窗口右上角关闭按钮时，是将应用静默缩至系统托盘继续下载，还是直接退出。 |
| **开机自启动** | 开启 / 关闭 | 关闭 | 注册操作系统开机启动项。自启时自动携带 `--hidden` 参数，保持静默托盘运行不打扰工作。 |
| **下载时抑制休眠** | 开启 / 关闭 | 开启 | 当有活跃下载任务进行时，自动向操作系统申请电源锁阻止系统进入睡眠，下载完毕后自动释放。 |
| **列表视图模式** | 卡片视图 / 紧凑表格视图 | 卡片视图 | 表格视图适合任务较多时的专业管理，支持自定义排序列与列显示开关。 |

## 2. 网络与代理 (Network & Proxy)

| 配置项 | 可选值 / 类型 | 默认值 | 详细说明 |
| :--- | :--- | :--- | :--- |
| **代理模式** | 直连 / 系统代理 / 手动代理 | 系统代理 | **直连**：不使用任何代理。<br>**系统代理**：读取操作系统的静态代理配置（Windows「Internet 选项」/ macOS 网络设置，含绕过列表）。不支持 PAC/WPAD 自动配置脚本，这类环境请改用**手动代理**。<br>**手动代理**：由用户自定义指定代理协议与服务器地址。 |
| **手动代理协议** | HTTP / SOCKS5 | HTTP | 支持配置局域网或本地科学上网代理（如 `127.0.0.1:7890`）。 |
| **默认 User-Agent** | 字符串 (String) | 内置现代 Chrome UA | HTTP 下载时向服务端发送的客户端身份标识。当访问部分高校或镜像站遭遇反爬拦截时，可在此自定义更新 UA。 |
| **连接超时** | 秒数 (10 ~ 120s) | 30 秒 | 单个 HTTP 连接握手与空闲超时阈值。 |

## 3. 下载与调度 (Downloads & Scheduler)

limedl 的并发调度引擎支持传统队列与先进自适应算法：

| 配置项 | 可选值 / 类型 | 默认值 | 详细说明 |
| :--- | :--- | :--- | :--- |
| **默认下载目录** | 本地文件路径 | 系统的“下载”文件夹 | 新建任务时的默认保存路径。 |
| **调度模式** | 传统队列 (Traditional) / 智能自适应 (Automatic) | 智能自适应 | **传统模式**：严格按照 FIFO 先入先出队列执行，最多同时激活 N 个任务。<br>**智能自适应模式**：大文件优先，根据所有活跃任务的剩余字节与优先级，全局动态重分配并发线程预算。 |
| **最大并行任务数** | 1 ~ 32 | 5 个 | 允许同时处于“下载中”状态的最大任务数量。 |
| **全局最大工作线程** | 4 ~ 128 | 32 线程 | 全局所有下载连接的工作线程上限，避免过度耗尽系统句柄。 |
| **AIMD 自适应模式** | 保守 / 平衡 / 激进 | 平衡 (Balanced) | **保守 (Conservative)**：提速谨慎，退避灵敏，适合弱网或易封 IP 的站点。<br>**平衡 (Balanced)**：平滑加法提速与乘法回退，适合绝大多数家庭宽带。<br>**激进 (Aggressive)**：快速跑满带宽，适合专线或内网镜像站。 |
| **自动校验和模式** | None / Blake3 / SHA-256 / SHA-512 | Blake3 (如有提供) | 下载完成后自动核对文件哈希，若发现数据损坏仅重下故障分块。 |

## 4. 速率限制与时间表 (Speed Limits & Schedule)

支持配置全局带宽配额与按时段动态调速：

- **全局下载限速**：单位为 `KB/s` 或 `MB/s`（设置为 `0` 表示不限速）。基于精准的令牌桶（Token Bucket）算法，纳米级开销，平滑流量尖峰。
- **全局上传限速**：控制 BitTorrent 的上行做种带宽，防止上行跑满导致下行 ACK 延迟增高。
- **定时限速计划 (Speed Schedule)**：
  可按星期和时段配置规则。例如：
  - `工作日 09:00 - 18:00`：限制下载为 `2000 KB/s`（保证办公/会议带宽流畅）；
  - `夜间 00:00 - 08:00`：解除限速（全速夜间挂机下载）。

## 5. BitTorrent P2P 设置 (BitTorrent Settings)

基于 **Irontide** 现代 P2P 引擎的全面调控：

| 配置项 | 推荐值 | 详细说明 |
| :--- | :--- | :--- |
| **监听端口** | 6881 (或随机范围) | P2P 传入连接的 TCP/UDP 监听端口。 |
| **UPnP / NAT-PMP 映射** | 勾选开启 | 自动在支持 UPnP 的家用路由器上开设端口转发，极大增加可连接 Peer 数量。 |
| **分布式哈希表 (DHT)** | 勾选开启 | 支持 Mainline DHT 网络，无需 Tracker 服务器即可通过磁力链接秒级获取种子信息。 |
| **对等节点交换 (PEX)** | 勾选开启 | 允许连接的 Peer 互相通告彼此已知的其他节点，加速 Swarm 群集扩张。 |
| **本地服务发现 (LSD)** | 勾选开启 | 自动探测同局域网内的其他做种客户端，利用千兆/万兆局域网满速内网互传。 |
| **加密传输** | 优先开启 (Preferred) | 优先使用加密连接以防范 ISP 深度包检测（DPI）限速，同时兼容不支持加密的旧节点。 |
| **做种分享率限制** | 1.0 ~ 2.0 (按需) | 当上传量达到下载量的指定倍数时自动停止做种（设为 0 为不限制分享率）。 |
| **全局公共 Tracker 列表** | 填入有效 URL | 每行一条 Tracker 地址。新建磁力或种子任务时会自动将这些 Tracker 注入任务中。 |

## 6. Aria2 RPC 接口设置 (Aria2 RPC)

limedl 内置了与标准 Aria2 完全兼容的 JSON-RPC 2.0 服务端，默认随应用启动：

- **启用 Aria2 RPC**：默认开启。
- **RPC 端口**：默认为 `6800`（如果与原装 Aria2 冲突可修改为其他端口，如 `6801`）。
- **RPC 密钥 (Secret Token)**：选填。若在局域网暴露或追求安全，可设置鉴权密钥。
- **允许跨域 (CORS)**：已内建配置，方便 Web 前端（如 AriaNg）跨域连接控制。

## 7. 存储与缓冲池 (Storage & Buffer Pool)

- **自动硬件介质探测**：
  Windows 下 limedl 会自动通过底层 Win32 API（`IOCTL_STORAGE_QUERY_PROPERTY` 查询寻道延迟特征）识别目标驱动器是固态硬盘（SSD）还是机械硬盘（HDD），并自动启用对应的优化模式：
  - **SSD 模式**：启用写入合并（Write Combining），批量落盘；
  - **HDD 模式**：启用双缓冲池（Double Buffering），单线程顺序落盘。
- **网络位置与 WSL**：
  UNC 网络共享、映射网络盘以及 Linux/macOS 上的网络挂载会被识别为**网络位置（介质未知）**，按 SSD 方式调度并在设置面板中列出——本地寻道探测对它们本来就没有意义。
  `\\wsl$\<发行版>` 不是网络存储：它背后的 9p/virtiofs 服务的是宿主卷上的 `ext4.vhdx`，limedl 会从注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Lxss` 解析出该虚拟盘路径，按宿主卷的真实介质（HDD/SSD）调度。
- **目录介质手动覆盖 (`disk_type_overrides`)**：
  在 **设置 → IO 实验室 → 目录介质覆盖** 中添加目录并指定 SSD/HDD。
  匹配是**规范化路径的前缀匹配**（Windows 下不区分大小写、忽略尾部分隔符），因此 `D:\Downloads` 同时覆盖其下所有子目录；嵌套条目最长者胜出。每一行都会显示该路径当前被探测到的介质，方便判断是否真的需要覆盖。
  保存后立即生效：不仅缓冲模式改变，该设备 I/O 队列的写线程数也会立即按新介质重建（HDD 单线程串行、SSD/网络 4 通道），无需重启。

## 8. 实验室 (Labs)

实验室收纳了 limedl 的独创实验性黑科技：

- **Cloudflare CDN 探针加速**：一键发起全国/全球 CDN 边缘节点测速，自动优选最低延迟并重定向底层 DNS 解析。
- **URL 重写规则 (URL Rewrite Rules)**：
  支持通过正则表达式将特定慢速源无缝改写为高速镜像。例如将 GitHub Release 官方链接自动重定向至高速镜像反代站点。
