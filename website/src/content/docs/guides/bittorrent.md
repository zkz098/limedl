# BitTorrent 协议与做种调优

limedl 深度集成了现代化 Rust 原生 BitTorrent 引擎（**Irontide**），具备完备的 P2P 协议族支持。

## 协议特性支持

- **分布式哈希表 (DHT)**：完全支持 Mainline DHT，无需中心 Tracker 即可通过磁力链接秒级获取种子元数据与 Peer 列表。
- **对等交换 (PEX)**：在 Peer 间互相宣告已知节点，迅速扩大蜂窝群（Swarm）。
- **本地服务发现 (LSD)**：自动探测局域网内的做种与下载节点，利用千兆/万兆局域网实现极速点对点传输。
- **UPnP / NAT-PMP 自动端口映射**：自动在路由器上打通传入连接端口，显著提升连通性并成为高可用活跃节点。

## 调优建议

1. **路由器 UPnP 开关**：确保上级路由器开启了 UPnP 功能，以便 limedl 自动映射监听端口。
2. **Tracker 列表维护**：虽然 DHT 能独立寻址，但配合优质公共 Tracker 列表能进一步加快冷门种子的初次握手。
3. **全局上传与做种比率**：在 **设置 -> BT 设置** 中，可根据宽带上行情况配置全局最大上传速率（默认为无限制 `0`）。
