# CDN 探针加速机制

在跨国网络或开源镜像站（如 GitHub Releases、各类 Linux 发行版镜像、开源模型托管等）下载时，传统的 DNS 解析往往受运营商本地缓存或 Anycast 路由策略影响，将用户导向高延迟或拥堵的 CDN 节点。

limedl 内置了 **CDN 探针加速模块**，通过多节点实时并发测速与动态 IP 优选，显著提升下载吞吐。

## 工作原理

1. **域名特征识别**：当检测到待下载链接处于支持的 CDN 范围（如 Cloudflare 网络覆盖的域名）时触发探测。
2. **多 IP 极速并发探测**：引擎向内置及用户维护的优质边缘 IP 列表发起毫秒级 TCP/TLS 握手测速与 HEAD 请求。
3. **选出最优低延迟节点**：按响应延迟与链路稳定性对 IP 进行评分排名，选出当前网络环境下质量最高的 IP 组合。
4. **底层 HTTP 传输重写**：在 Rust `reqwest` 传输层直接通过 `resolve` 将域名绑定至优选 IP，保留原始 SNI 与 Host 头部，确保安全握手与传输。

## 启用与调优

在 limedl **设置 -> 网络与 CDN** 界面中：
- **开启 CDN 探针**：勾选后在下载对应域名资源时自动生效。
- **自定义 IP 列表**：支持高级用户导入自测的洁净/高速 IP 列表。
