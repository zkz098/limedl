# 任务管理与并发策略

limedl 摒弃了传统下载器简单盲目设置固定连接数（如固定 16 或 32 线程）的做法，而是采用类似现代网络拥塞控制的 **AIMD（Additive Increase Multiplicative Decrease）** 动态自适应并发策略。

## 创建下载任务

在桌面端界面中，可以通过以下几种方式创建任务：
1. **快捷键与剪贴板**：复制有效 URL 或磁力链接后，切换至 limedl 窗口会自动弹窗识别。
2. **工具栏点击**：点击界面左上角 `+ 新建` 按钮，粘贴链接。
3. **拖拽导入**：直接将 `.torrent` 种子文件拖拽入 limedl 窗口。
4. **浏览器一键接管**：通过配合浏览器扩展（见生态章节），点击网页文件直接唤醒下载。

## AIMD 动态并发调控

- **平滑起步**：任务初始时分配 2~4 个工作连接并探测服务端 `Accept-Ranges` 与分块响应延迟。
- **加法探测 (Additive Increase)**：若当前块传输平稳且无丢包抖动，工作池逐步增加连接数以跑满下行带宽。
- **乘法退避 (Multiplicative Decrease)**：一旦检测到服务端限流（HTTP 429 / 503）或连接重试率升高，迅速减少并发并平滑回退，避免触发服务端永久封禁 IP。
- **镜像故障转移 (Mirror Failover)**：当配置了多个镜像源时，若某个镜像连接超时，引擎会自动无缝切向备用镜像，保障大文件下载不中断。
